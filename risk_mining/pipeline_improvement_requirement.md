我们可以将关键时刻的提取规则细化为以下三大类判据集：

### 1. 锚点 $T_{peak}$ (冲突极值点) 的提取规则

这是整个事件的核心，必须最先确定。在路口场景中，不能仅仅依赖 TTC（碰撞时间），因为车辆经常是交叉轨迹，而不是追尾。

**提取逻辑：** 遍历时间轴，寻找以下指标的**全局最小/最大值点**。

| 规则名称 | 计算公式/逻辑 | 适用路口场景 |
| :--- | :--- | :--- |
| **规则1：最小 TTC (Time-to-Collision)** | $\min(TTC_t)$ 且 $TTC_t < 2.5s$。计算主车与干扰车在当前速度矢量下的预计碰撞时间。 | 前车切入、同向急刹、对向直行冲突。 |
| **规则2：最小 PET (Post-Encroachment Time)** | $\min(PET_t)$ 且 $PET_t < 2.0s$。即一辆车离开冲突区域，另一辆车到达该区域的时间差。 | **路口交叉博弈**（如直行遇无保护左转、横穿马路）。这是上帝视角数据集最容易精准计算的指标。 |
| **规则3：最大运动学突变** | $\max(\|a_{lon}\|)$ (纵向加速度极值) 或 $\max(\|Jerk\|)$ (加加速度极值)。 | 当没有发生真实碰撞风险（TTC不低），但主车被“吓一跳”产生了猛烈操作时（如急刹、猛打方向）。 |

> **实操建议：** 取这三个指标触发的**最早时间点**或**最危险点**作为 $T_{peak}$。

注意：路口交互中的TTC可能抖动剧烈，我们优先考虑PET

### 2. 回溯起点 $T_{start}$ (致因时刻) 的提取规则

确定了 $T_{peak}$ 后，我们要在时间轴上向左（历史方向）滑动，寻找“是什么打破了原本的安全状态”。

**提取逻辑：** 从 $T_{peak}$ 开始 $t = t - \Delta t$，检查每一帧，直到触发以下边界条件。

| 规则名称 | 计算公式/逻辑 | 语义解释 |
| :--- | :--- | :--- |
| **规则1：拓扑状态翻转 (Topological Flip)** | 寻找 `is_occluded` 或 `is_in_blind_zone` 从 `True` 变为 `False` 的那一帧。 | **鬼探头/盲区杀手**。风险的源头是“突然看见”。 |
| **规则2：物理边界入侵 (Boundary Crossing)** | 寻找干扰车的 Bounding Box 与**路口冲突区多边形 (Conflict Zone Polygon)** 发生交集的初始帧，或跨越车道线的初始帧。 | **强行加塞 / 闯红灯 / 抢行**。风险的源头是“不该进来的车进来了”。 |
| **规则3：意图突变 (Intent Mutation)** | 寻找干扰车的横向速度 $|v_{lat}|$ 突然大于 $0.5m/s$，或者纵向加速度 $a_{lon}$ 从 $0$ 突变为 $>2m/s^2$ 的那一帧。 | **犹豫后的突然启动**。风险的源头是干扰车打破了静止/匀速的预测模型。 |
| **规则4：兜底时延 (Fallback Latency)** | 如果以上都找不到，强制设定 $T_{start} = T_{peak} - T_{reaction}$ （通常取 $1.5s \sim 2.0s$）。 | 确保图结构至少包含一段前置历史。 |

### 3. 延展终点 $T_{end}$ (消散时刻) 的提取规则

从 $T_{peak}$ 向右（未来方向）滑动，寻找系统重新回归稳态的时刻。这一步决定了这个场景片段的长度。

**提取逻辑：** 从 $T_{peak}$ 开始 $t = t + \Delta t$，直到满足以下稳定条件，且**至少维持 $N$ 帧 (例如 1秒)**。

| 规则名称 | 计算公式/逻辑 | 语义解释 |
| :--- | :--- | :--- |
| **规则1：风险解除 (Risk Clear)** | $TTC > 5.0s$ 且两车相对距离持续增大 ($\vec{v}_{rel} \cdot \vec{p}_{rel} > 0$)。 | 冲突已经过去，双方各走各的路。 |
| **规则2：动力学归零 (Dynamics Zeroing)** | 主车速度 $v_{ego} < 0.1m/s$ 且加速度 $a_{lon} \approx 0$。 | 主车被彻底逼停（或发生碰撞）。事件在此刻进入静态。 |
| **规则3：脱离关注区 (Out of ROI)** | 干扰车驶出主车前方 $50m$ 的感兴趣区域，或转入背离主车行驶方向的车道。 | 干扰源消失，无需继续追踪。 |
